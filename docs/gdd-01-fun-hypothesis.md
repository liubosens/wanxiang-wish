| 维度 | 结论 | 备注 |
|------|------|------|
| 品类 | 抽卡 + 半养成 + 收集图鉴 | "穿越不同抽卡场景"是外壳 |

## 1. Fun Hypothesis（一句话地基）

> **这游戏好玩的核心是**：用**一个通用资源池**在**多个经典抽卡题材的世界里穿梭抽卡**、填满**跨世界观图鉴**——"差一张就满"的临近感，叠加半养成的随时小额正反馈，共同制造**低门槛、高保留的收集多巴胺**。

**设计者批注**：你描述里"穿到原神/三国杀/王者不同模式"最诱人也最贵。我的判断——**"穿越"是调味，"收集 + 抽卡多巴胺"才是必须被验证的假设**。先验证后者，前者用换皮做，不要先建 4 套引擎。

## 2. Design Pillars（5 条，不可妥协）

| # | Pillar | 玩家体验标准 | 违反时的后果 |
|---|--------|--------------|--------------|
| P1 | 收集即脊梁 | 任意一张卡获取，图鉴里都有明确格子与完成度 % | 用户看不到"还差多少"→ 保留崩 |
| P2 | 一抽即一回合 | 单次抽卡 10–30s 内走完 期待→揭示→得失 弧 | 非酋空手无补偿 → 弃游 |
| P3 | 随时停随时得 | 离线产出 + 每日小额，非 session 玩家也有 accrual | 回归门槛高 → 流失 |
| P4 | 概率透明 | 保底进度可见、可预期；零"被骗感" | 泛休闲零容忍，且涉合规红线 |
| P5 | 穿越是皮不是核 | 多世界观用 banner / 主题轮换呈现，不各自成独立子系统 | scope 爆炸，原型永不上线 |

## 3. Core Loop 三层拆解

### 3.1 Moment-to-Moment（0–30s：一抽）
- **动作**：开包 → 看保底进度 / 概率 → 揭示动画 → 结果落定
- **反馈通道**：视觉（稀有度配色闪光）/ 音频（抽中音效）/ UI（图鉴弹窗 + 完成度 ↑）
- **奖励**：新卡 → 图鉴；重复卡 → **转化资源**（防沉没感，见 §4）
- **失败信号**：抽完 30s 内无任何 UI 变化、无音效、图鉴不跳动 → 反馈通道坏

### 3.2 Session Loop（碎片 5–15min：资源 → 抽 → 养）
- **目标**：用当日资源做 N 次抽卡 + 推进 1 条养成线
- **张力（唯一需动脑的决策）**：**攒着等新 banner vs 现在抽** —— 这点必须被服务好，否则 sesson 无脑
- **结果**：图鉴完成度 ↑、养成数值 ↑、资源余量
- **失败信号**：玩家永远"刚好不够抽"且无处可攒 → 无力感；或资源溢出无消耗 → 通胀

### 3.3 Long-term（小时–周：跨世界观图鉴）
- **进阶**：原神区 / 三国杀区 / 王者区图鉴逐步填满，养成解锁更高 tier
- **保留钩子**：周期新 banner（新题材主题）、图鉴里程碑奖励、限时活动
- **社交循环**：**[PLACEHOLDER]** 泛休闲小程序社交可后置；先假设轻量（好友赠送 / 排行榜），需定义是否做

## 4. 经济 Sources & Sinks（先画，否则通胀）

```
Sources（钱从哪来）              Sinks（钱到哪去）
───────────────────             ──────────────────────
每日登录           ─┐
日常/周常任务      ├─→ 资源池 ─→ 抽卡消耗（卡包单价）  ✅ 主 sink
离线挂机产出       │           └→ 养成消耗（升级材料）  ✅ 吃重复转化
首次图鉴达成奖励   │
付费（可选）     ─┘
重复卡转化资源    ───────────→ 二次 source ⚠️ 必须有 sink
```

**红线**：重复卡转化 = 二次 source，若养成消耗吃不掉它，通胀只是时间问题。所以 P3 的"养成消耗"必须设计成**长期吞金黑洞**（升星 / 突破材料随 tier 指数增长）。

## 6. 验证路径（MVP 怎么证明假设）

1. **不要先建 4 个引擎**。用一套通用抽卡 + 图鉴骨架，把"原神 / 三国杀 / 王者"做成 3 个**换皮 banner**（同系统不同美术文案）。
2. **先验证 P1 + P2**：找 10–20 个泛休闲用户，只给"攒资源 → 抽卡 → 看图鉴跳动"，测"差一张就满"的临近感是否让人想再开一次。
3. **失败信号先定义**：① 首日留存 < [PLACEHOLDER]%；② 抽卡后 24h 内无回访；③ 图鉴完成度增速与回访不相关 → 任一出现，fun hypothesis 错，回炉。
4. **通胀监控**：内测第 2 周查资源存量中位数，若远超单抽消耗 ×10，sink 不足，回 §4 加黑洞。
