# 万象心愿 · 多抽卡机制重设计（v0.4）

> 触发：用户修正——"想要的是抽卡概率独立，原神的保底机制和三国杀的全服保底机制完全不同，是不同的玩法。"
> 结论：我之前 P5「穿越是皮不是核 / 换皮 banner」是误读。穿越不同世界 = **抽卡机制本身不同**，这才是核心。

## 1. 修正后的 Fun Hypothesis
> **这游戏好玩的核心是**：在多个抽卡世界间穿梭，每个世界有**独立概率 + 独立保底机制**；玩家驾驭三种"与运气的关系"（原神=赌个人规律 / 三国杀=赌社区运气 / 王者=不赌攒积分）本身成为一种玩法。跨世界图鉴收集 + 统一养成层，构成低门槛、高复玩。

## 2. 三世界抽卡机制模型（核心差异）

| 世界 | 机制类型 | 规则（[PLACEHOLDER] 待 playtest） | 玩家心理 |
|------|----------|----------------------------------|----------|
| 原神区 | 个人阶梯保底（私域） | 74 软保底概率递增，90 硬保底必出 5★；小保底 50% 出 UP，歪则大保底 100% 出 UP | 自己攒、自己摸规律，掌控感 |
| 三国杀区 | 全服累积保底（公域） | 全服计数器阈值 T 后，下一次任意玩家抽卡必出 5★并清零；运气与社区绑定 | "全服快保底了，现在抽稳" / "我顶出了保底" |
| 王者区 | 积分兑换（确定） | 每抽 +1 荣耀积分，满 N 兑换指定 5★，零赌博焦虑 | 目标型，"我就想要某个英雄" |

**设计落点**：三世界形成"赌个人 / 赌社区 / 不赌"的光谱，玩家按性格选世界——这是"不同玩法"的最小可行表达，且只建 3 个抽卡-规则模块，不建 3 套引擎。

## 3. 设计张力（呈现，不假装一致）
- **认知负荷 vs 泛休闲**：3 套规则对纯休闲偏重。Resolution：每世界用 10s 可懂的 UI 隐喻（私域进度条 / 全服进度条 / 积分槽）；首阶段可只开 2 世界，第 3 个 liveops 加。
- **共享货币 vs 独立概率**：用共享"星砂"在各世界抽，各世界套自己规则 → "概率独立"成立，切换成本最低。若改独立货币更清晰但更碎，待定。
- **抽卡层多样 + 养成层统一**：升星 / 试炼（v0.3 保留引擎）作为跨世界通用层，既满足"不同玩法"又控 scope。

## 4. MVP Scope
3 个抽卡-规则模块 + 1 个共享图鉴 + 统一升星/试炼。原型 `prototype/paper-prototype.html` 已迭代到 v0.4。

## 5. 验证重点（v0.4）
- 玩家是否因"不同保底机制"产生**世界偏好**（有人只蹲原神、有人爱全服博弈）？
- 是否主动**研究规则**（问"这个世界的保底怎么算"）？
- 若三世界无偏好差异 → "机制多样"假设错，回炉（可能用户要的是完整玩法差异，非仅抽卡规则）。

## 6. 待你确认
"不同玩法"是否仅指**抽卡机制不同**（本稿假设）？还是你也想让集齐后的**实际玩法**不同（原神区开放探索 / 三国杀区出牌对战 / 王者区推塔）？后者 scope 大一个量级，需单独规划。
