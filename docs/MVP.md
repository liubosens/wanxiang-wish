# MVP 验收清单

## 目标

跑通共享层 + 三种机制族代表场景，可在开发者工具内完整演示「获取货币 → 抽奖 → 入包 → 历史 → 公示」。

## 必须有

- [x] 概率馆入口（卡池 / 开箱 / 转盘）
- [x] A1 标准单抽 / 十连 + A3 保底进度条
- [x] B1 铜银金宝箱
- [x] C2 权重转盘
- [x] 本地钱包扣费与余额展示
- [x] 背包 / 图鉴首次获得标记
- [x] 抽卡历史列表
- [x] 概率公示页（读 pool 配置）
- [x] 统一 Roll Engine（`shared/roll-engine.js` + 云函数 `draw`）
- [x] 本地 Mock 模式（无云开发可玩）

## 本版不做

- 真实支付 / 激励视频
- UP 定轨、箱庭、Bingo 等非 MVP 场景
- 正式运营后台与全服排行

## 手工验收步骤

1. 打开小程序 → 我的 → 领取每日补给
2. 概率馆 → 标准祈愿 → 单抽 / 十连，观察保底条变化
3. 开箱 → 打开铜/银/金箱
4. 转盘 → 转动一次
5. 背包可见物品；记录可见流水；公示可见各池概率文案
